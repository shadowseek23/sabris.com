# Obsahové zrcadlo

Zdroj: https://web-dev.sabris.com/. Nikoli produkce. Původní znění v pages, vykreslené HTML v html, strukturované DOM podklady v raw, desktop screenshoty a vybrané mobilní stavy v screenshots. Úplnost a omezení viz manifest.md. Originální média používaná novým webem jsou v apps/web/public/media; assets/manifest.json obsahuje zdrojové URL a SHA-256.
