# Předávka zdroje

Opakované prvky: header, jazyková navigace, patička, titulkový banner, breadcrumbs, obsahové sekce, reference, seznamy přínosů, CTA. Homepage má desktopový přepínač řešení a mobilní odkazy, ruční cyklický carousel zákaznických videí a carousel log.

Parametry v interactions/home.json: 500ms posun, autoplay off, loop on. Hlavní karty 650×380 px, 48px mezera. Loga saturate(0%) brightness(130%) → plná barva. Reference scale(1.04), .3s přechod, překryv opacity .6 → 0. Video play tlačítko hover scale1.4 s oranžovým stínem.

Zachovat URL převzatých stránek. Partnery přesunout na Smart potravinářství, vyřazené služby na aktuální nabídku. Formulář newsletteru zdroje není aktuální proces. Kontakt zdroje obsahuje pouze adresy a kontaktní odkazy.

Nejistoty: aktuální benefity, certifikace, nové reference a fotografie. Zdroj uvádí staré počty a neplatná partnerství; nesmějí být zaměněny za současný stav. Rozsah a výjimky viz manifest.
